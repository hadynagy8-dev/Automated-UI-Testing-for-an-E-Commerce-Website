Project: [Automated UI Testing for an E-Commerce Website]  
Objective:. To design and implement a clean, maintainable, and automated UI testing suite for the main user journeys of a public e-commerce website using Selenium WebDriver. 
Description: The project focuses on automating key e-commerce user journeys, including login, product search, adding products to the shopping cart, and checkout. The team will develop manual test cases first, then automate them using Selenium WebDriver with appropriate assertions and waits. The automation code will finally be refactored using the Page Object Model (POM) to improve maintainability and reusability.
